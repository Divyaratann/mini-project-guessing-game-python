# 🎮 Python Number Guessing Game

A simple and interactive **Number Guessing Game built using Python**. The computer randomly selects a lucky number between 1 and 50, and the player has to guess the correct number.

The game provides hints such as **"Too Low!"** and **"Too High!"** to help the player find the correct number.

## ✨ Features

- 🎲 Random number generation
- 🔢 Guess a number between 1 and 50
- ⬇️ "Too Low!" hint when the guess is smaller than the lucky number
- ⬆️ "Too High!" hint when the guess is greater than the lucky number
- 🏆 Winning message when the correct number is guessed
- 🔁 Repeated guesses until the player wins
- 👋 Thank-you message when the game ends

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** `random`
- **Concepts:** Functions, loops, conditional statements, user input, and type conversion

## 🎯 How to Play

1. Run the Python program.
2. Enter a number between 1 and 50.
3. Read the hint displayed by the program.
4. Guess again based on the hint.
5. Find the correct number to win the game!
